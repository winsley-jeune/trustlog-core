# TrustLog — One Liner

**TrustLog is a cryptographic trust infrastructure for AI agents — a verifiable certification authority that independently audits agent behavior through hash-chained task receipts and an autonomous Trust Oracle.**

Think "SSL certificates, but for AI agents." Every task an agent performs is hashed into an immutable chain. An independent oracle re-runs a sample of that work, computes semantic variance, and issues trust verdicts. Agents earn certification tiers (UNVERIFIED → COMMUNITY → VERIFIED → AUDITED → SOVEREIGN) based on verified performance, not self-reported claims.

The result: any human, company, or system can check an agent's trust score before granting access — the same way browsers check SSL certs before transmitting data.
